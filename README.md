# TechRent Platform - ระบบเว็บแอปพลิเคชันเช่าอุปกรณ์ IT ครบวงจร

แพลตฟอร์มบริหารจัดการธุรกิจเช่าอุปกรณ์ไอที (Laptops, Monitors, Cameras, GPUs, Tablets) แบบครบวงจร พัฒนาด้วย Next.js 14, React, TypeScript, Tailwind CSS, และ SQLite ผ่าน Prisma ORM

---

## ฟีเจอร์เด่นตามข้อกำหนด (Key Features)

### 1. ระบบผู้ใช้งานทั่วไป / ลูกค้า (Customer Module)
- **1.1 การจัดการบัญชีและยืนยันตัวตน (Authentication & KYC)**
  - สมัครสมาชิก / เข้าสู่ระบบด้วย Email/Password และ Google Mock Social Login
  - อัปโหลดเอกสารยืนยันตัวตน (บัตรประชาชน / บัตรนักศึกษา) พร้อมระบุบุคคลติดต่อฉุกเฉิน
  - ระบบตรวจสอบและแสดงสถานะ KYC แบบเรียลไทม์ (Approved, Pending, Rejected)
  - จัดการโปรไฟล์ ที่อยู่จัดส่ง และเบอร์โทรศัพท์
- **1.2 การค้นหาและดูอุปกรณ์ (Catalog & Browsing)**
  - ค้นหาและคัดกรองตามหมวดหมู่ (โน้ตบุ๊ก, จอคอม, กล้อง, การ์ดจอ, แท็บเล็ต) แบรนด์ และสเปก
  - หน้ารายละเอียดอุปกรณ์ (Product Detail) แสดงสเปกละเอียด อุปกรณ์เสริมในชุด ราคาเช่ารายวัน/รายสัปดาห์ และเงินประกันมัดจำ
  - **Availability Calendar (ปฏิทินตรวจสอบคิวว่าง):** แสดงปฏิทินรายเดือนระบุจำนวนเครื่องว่าง พร้อมแถบสีสถานะ (เขียว = ว่าง, ส้ม = เหลือน้อย, แดง = เต็ม)
- **1.3 การทำรายการเช่า (Booking & Rental Flow)**
  - Date Range Picker เลือกช่วงวันเริ่มต้นและสิ้นสุด
  - **Pricing Engine อัตโนมัติ:** คำนวณจำนวนวันเช่า ส่วนลดรายสัปดาห์ ค่ามัดจำ และยอดสุทธิ
  - **PromptPay QR Code:** สร้าง QR มาตรฐาน EMVCo ตามยอดเงินจริง พร้อมอัปโหลดสลิปโอนเงิน หรือเลือก Mock Payment Gateway
  - **สัญญาเช่าดิจิทัล (Digital Contract):** ติ๊กยอมรับข้อกำหนดการดูแลรักษา อัตราค่าปรับส่งช้า และการหักกลบลบหนี้
- **1.4 การติดตามสถานะและประวัติ (Tracking & Order History)**
  - ไทม์ไลน์สถานะคำสั่งเช่า: `Pending` → `Approved` → `Active (In-use)` → `Returned` → `Completed`
  - พิมพ์/ดูใบเสร็จรับเงิน ใบส่งมอบอุปกรณ์ และใบสรุปการคืนเงินมัดจำ (Printable Invoice/Receipt)

---

### 2. ระบบผู้ดูแลระบบ / เจ้าหน้าที่ (Admin & Staff Module)
- **2.1 จัดการอุปกรณ์และสต็อกระดับชิ้น (Inventory & Serial Number Tracking)**
  - Product CRUD เพิ่ม ลบ แก้ไขสเปก รูปภาพ ราคาเช่า และเงินมัดจำ
  - **Serial Number Level Tracking:** ผูก S/N เฉพาะกับอุปกรณ์แต่ละเครื่อง ระบุสถานะรายชิ้น (`AVAILABLE`, `RENTED`, `MAINTENANCE`, `DAMAGED`)
- **2.2 ตรวจสอบคำขอเช่า (Order Approval & Verification)**
  - ตรวจสอบเอกสาร KYC (รูปบัตรประชาชน) พร้อมปุ่ม Approve / Reject
  - ตรวจสอบสลิปการโอนเงิน PromptPay พร้อมปุ่มยืนยันยอดชำระ
  - **Assign Asset:** เลือก Serial Number ของเครื่องว่างจริงเพื่อผูกเข้ากับคำสั่งเช่า
- **2.3 ขั้นตอนส่งมอบและตรวจรับคืน (Check-out & Check-in Inspection)**
  - **Check-out (ก่อนส่งมอบ):** บันทึกรูปถ่ายสภาพเครื่อง บันทึกการส่งมอบ เปลี่ยนสถานะเป็น `Active (In-use)`
  - **Check-in (รับคืนเครื่อง):** บันทึกรูปถ่ายสภาพเครื่องหลังใช้งาน
  - **ระบบคำนวณค่าปรับอัตโนมัติ:**
    - ค่าปรับส่งคืนล่าช้า (Overdue Days × 1.5 เท่าของค่าเช่ารายวัน)
    - ค่าปรับกรณีเครื่องชำรุดเสียหาย (Damage Fee) ที่ประเมินโดยเจ้าหน้าที่
  - **สรุปคืนเงินมัดจำ (Refund Calculation):** เงินมัดจำ - ค่าปรับ = ยอดโอนคืนสุทธิ พร้อมแนบสลิปการโอนคืน และเปลี่ยนสถานะเป็น `Completed`
- **2.4 สรุปและรายงานผล (Dashboard & Reports)**
  - แดชบอร์ดสรุปรายได้รวม, ค่ามัดจำในระบบ, จำนวนคำสั่งเช่า, และกราฟ 5 อุปกรณ์ยอดนิยม
  - รายงานเครื่องที่ใกล้ครบกำหนดคืน (Due Soon 24-48 ชม.)
  - รายงานเครื่องที่คืนล่าช้าเกินกำหนด (Overdue / Risk Alert)

---

### 3. ระบบเบื้องหลังและการแจ้งเตือน (System & Background Logic)
- **Overlap Prevention Logic:** ฟังก์ชันตรวจสอบช่วงวันที่ลูกค้าเลือก ป้องกันการจองชนกันอย่างแม่นยำ
- **Notifications System:** ระบบแจ้งเตือน In-app พร้อมศูนย์จำลองส่งแจ้งเตือนผ่าน LINE Official Account (LINE Messaging API Flex Message) และ Email แจ้งเตือนล่วงหน้า 1 วันก่อนครบกำหนดคืน
- **Activity Log / Audit Trail:** บันทึกประวัติการทำงานของแอดมินทุกขั้นตอน (ใครเป็นคนอนุมัติ, ใครเป็นคนผูก S/N, ใครเป็นคนตรวจรับคืน, ใครเป็นคนโอนคืนมัดจำ) พร้อม IP Address

## วิธีการรันระบบ (How to Run)

```bash
# 1. ติดตั้งไลบรารี
npm install

# 2. เตรียมฐานข้อมูลและสร้างข้อมูลทดสอบ
npx prisma generate
node prisma/seed.js

# 3. รันเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```

เปิดเว็บเบราว์เซอร์ที่: **`http://localhost:3000`**
